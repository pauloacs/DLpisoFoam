# Deprecated Solver Assets

This folder contains historical solver implementations and tutorial snapshots.
They are kept for reproducibility, not as the supported build/run path.

- `other_solvers_2d/`: older alg1, alg2, and delta solver project.
- `tutorials/DLpimpleFoam_delta_delta_shift/`: superseded delta-delta AUTO example.
- `tutorials/DLbuoyantPimpleFoam_auto/`: thermal AUTO example whose solver source is not tracked here.

For supported workflows, use the [classic/offline guide](../classical/README.md)
or the [AUTO guide](../auto/README.md), and follow build commands from the
[repository README](../README.md).
